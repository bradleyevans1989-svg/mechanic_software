# Sample import files

Made-up data for trying **Settings → Import from other software**.

| File | What it shows |
| --- | --- |
| `workshop-software-customers.csv` + `workshop-software-vehicles.csv` | Workshop Software's layout (from its published import templates): customers and vehicles in two files linked by IMPORTED ID. Includes a company with a contact, a bad email, a blank customer row and a car whose owner isn't in the file. Sam Taylor matches the demo workshop's customer. |
| `workshop-software-products.csv` | Workshop Software products: stock, a labour item (type J), negative stock, a repeated part number. |
| `mechanicdesk-style-export.xlsx` | One workbook with Customers, Vehicles and Inventory sheets, linked by UUID. MechanicDesk doesn't publish its export columns, so these are a guess; Alex Nguyen and rego XYZ789 match the demo workshop. |
| `simple-customer-list.xlsx` | A hand-kept spreadsheet: a title row, one row per car, phone numbers that lost their leading 0, Excel dates, a date written as "soon". |
